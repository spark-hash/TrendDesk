# TrendDesk · 美股趋势工作台

个人使用的本地 Web 工具。Python 后台通过 moomoo OpenD 读取美股和美股 ETF 行情，浏览器展示趋势、关键价位和信号。没有交易上下文、解锁交易或下单代码。

## Windows x64 发布版

从 [GitHub Releases](https://github.com/spark-hash/TrendDesk/releases/latest) 下载 `TrendDesk-Windows-x64.zip`。完整解压后，双击 `TrendDesk.exe` 启动本机服务并打开工作台。发布包自带 Python。实时行情需要先登录 Moomoo OpenD。要停止后台，在 Windows 通知区域右键 TrendDesk，选择「退出并停止服务」。

从托盘右键菜单选择「检查更新…」查看 GitHub 稳定版。点击确认后才下载并校验 SHA-256，退出托盘服务后重新打开原入口以启用新版。

在已安装依赖的开发环境中，运行 `.\.venv\Scripts\python.exe scripts/package_windows.py` 可重新生成 ZIP。

## 从源码启动

1. 启动并登录 **Moomoo OpenD**，保持运行。默认 API 端口为 `11111`。
2. 双击项目根目录的 **start.cmd**。
3. 浏览器打开 **http://127.0.0.1:8765**。只监听本机回环地址，不部署到公网。
4. 「行情与提醒设置」可修改 OpenD 端口、放量倍数、接近关键位阈值，并开启 Windows 桌面提醒。

首次安装依赖或 Python 环境损坏时，先运行 `setup.cmd`。它使用已安装 Python 或 Codex 附带的 Python，在项目内建立 `.venv`。推荐 Python 3.12。也可指定：

```powershell
./scripts/setup.ps1 -PythonPath 'C:/path/to/python.exe'
```

关闭网页只关闭界面；后台继续监控。双击 **stop.cmd** 停止本项目后台，OpenD 保持运行。电脑关机、休眠、网络中断或 OpenD 离线时无法持续监控。

## 已实现

- 最多 50 只美股自选：增删、搜索、按接近触发程度或相对 SPY 强弱排序。
- SPY / QQQ 市场参考。它们是 ETF，不是指数点位。
- moomoo 实时报价推送、日线 / 60 分钟 / 15 分钟 K 线推送与历史补齐。
- SVG 蜡烛图、MA20 / MA50、成交量、小时支撑阻力；鼠标悬停查看 OHLCV，滚轮缩放、拖动平移。
- 基于已收盘 K 线的多周期趋势解释、20 日相对 SPY 收益差。
- 顺势突破、回调转强、接近突破位三类观察提醒。
- 手动录入做多持仓、保护价与目标价提醒；不会读取券商账户持仓。
- SQLite 信号日志：时间、价格、规则与持仓快照、已读状态、CSV 导出。
- 后台 Windows 桌面通知（默认关闭，在设置开启）；页面关闭后后台仍可通知。系统专注模式等会影响通知可见性，站内日志不受影响。
- 断线重连、历史补齐、新鲜度检测、持久化去重、只读演示模式。
- 历史回测：分别评估顺势突破、回调转强和 15 分钟开盘区间突破，支持参数、净值和回撤曲线、逐股统计、交易明细、CSV、保存结果、取消任务。

## 历史回测（V1.1）

点击「历史回测」，默认当前自选股、最近约 180 天。最多 20 只股票、365 天跨度；结束日期不能超过最近已收盘交易日。每次只运行一个任务；关闭网页后仍继续，重启后台会将未完成任务标记为中断。下拉框可查看最近 20 次结果。

两种策略各自使用独立的 $100,000 本金，按输入股票数等分为互不转移的资金份额。每股每策略最多一笔做多持仓、不加杠杆，默认风险为该股可用资金的 1%。共用实时分析规则，逐根仅传入当时已完成的日线、小时线和 15 分钟线，排除未来数据；连续成立的信号去重。

信号确认后的下一根常规时段 15 分钟 K 线开盘模拟成交，可隔夜；该理想化开盘成交不包含实时推送及 3 秒确认延迟。买价加滑点、卖价减滑点，默认每边费用 2.5 bps、滑点 5 bps（1 bps = 0.01%）。保护价固定为信号参考价，目标价按模拟实际入场价加 2R；跳空跌破保护价按开盘退出，同根保护价与目标均触及优先保护价。默认最多持有 130 根，样本最后一根强制退出。

胜率按扣费后盈利的已平仓交易占比计算；没有交易时显示空值。账户收益含现金部分。最大回撤为每根 15 分钟收盘净值相对历史峰值的最大下降比例，包含浮盈浮亏与预计平仓手续费，不代表逐笔盘中最大回撤。模拟使用前复权价格和碎股，不另计现金分红、税费、利息、实际最低佣金或市场冲击。退出时刻显示退出 K 线结束时刻。

运行前严格验证三周期在测试范围的交易日历覆盖；缺失的股票不纳入模拟并展示原因，其资金保持现金，不能把成功股票重新放大资金比例。预热数据另取日线 400 天、小时线 90 天和 15 分钟线 14 天。缓存独立存于 `data/backtests/*.json.gz`，同日同股票同范围重跑复用；结果与当次参数、规则版本存入 SQLite。回测仍需 OpenD 连接。

moomoo 历史 K 线额度按最近 7 天请求过的不同标的计数，到期释放，不是永久消耗或固定周一统一清零；同一标的重复查询、换周期不会在有效期内重复占用。实时订阅额度是同时占用量，满足最短订阅时间后取消会释放。账户额度上限及行情权限可能随账户条件变化。官方依据见文末链接。

## 规则与时段

第一版仅做多、仅分析美股常规时段行情。收市后保留 2 分钟确认窗口，处理最后一根常规时段 K 线，不分析盘后新 K 线。交易日历采用 XNYS，覆盖休市、夏令时和提前收市；不是简单按周一到周五判断。页面显示美东时间，下一开盘同时显示新加坡时间。

趋势：价格 > MA20 > MA50 且 MA50 高于 5 根前为上升；反向为下降；其余为震荡 / 过渡。至少 55 根已完成 K 线才判断趋势。MA200 会计算并保留在 API 中，第一版不作为入场过滤器。

顺势突破：日线向上、小时线不下降；15 分钟收盘从小时区间上沿下方突破上沿，成交量至少为前 20 根 15 分钟均量的 1.5 倍（可设置），突破延伸不超过 0.75 个 15 分钟 ATR。小时区间只使用候选 15 分钟 K 线开始前已完成的最近 20 根小时 K 线。

回调转强：满足相同趋势与成交量条件；前 6 根 15 分钟 K 线触及小时 MA20 ± 0.25 小时 ATR，未跌破小时区间低点，最新收盘突破前 3 根 15 分钟高点并回到小时 MA20 上方。

接近突破位按已收盘 15 分钟价格计算。参考保护位为最近 7 根 15 分钟低点减 0.2 ATR；2R 目标以最新已收盘价格和参考保护位计算，是风险倍数示意，不是预测价。实际持仓保护位由用户录入。

正式入场信号只处理刚收盘 120 秒内的 K 线，至少等结束时间后 3 秒；行情报价也须在 120 秒内。交易日刚开盘时使用最近已完成日线和小时线。断线期间不会产生提醒，恢复后不补发过时入场信号。保护价／目标价按新鲜报价触发，每份持仓计划每种风险提醒只触发一次；编辑计划会重新启用。

入场提醒按“股票 + 信号类型 + 条件成立的一段过程”去重。条件失效后才重新启用；去重状态落盘，重启不重复发送。同一事件可以从日志回看。最新报价可能来自有限交易场所，盘口、逐笔或成交量不应自动视为全市场合并数据。

## 数据口径

- 只接入 OpenD 的行情上下文 `OpenQuoteContext`。
- 历史查询显式给定开始和结束日期，日线约 500 个自然日、小时线约 90 天、15 分钟约 25 天；分页与限频自动处理。
- 全部 K 线使用 **前复权 QFQ、常规时段 RTH**。每天重新加载历史窗口，避免拆股等调整后拼接旧复权价格。
- 实际 OpenD 美股分钟 K 线以**结束时间**标记。适配器统一转换为内部**开始时间**；最后不足 60 分钟的 K 线按交易所收市截断。
- 缺失、过期、不完整数据不触发入场提醒；超过 90 秒仍未补齐时会重新请求历史。低流动性股票可能因无新成交而暂停提醒，这比使用陈旧价格发信号更保守。
- 演示模式所有价格由固定随机种子合成，明显标注，不写入真实数据库、不保存演示持仓或生成真实通知。
- moomoo 订阅和历史标的额度与账户有关；程序显示实际历史额度，本连接通常每个标的使用 4 个订阅类型。API 订阅权限可能随券商调整。

## 数据、日志与维护

- `data/trenddesk.db`：自选、设置、缓存、持仓计划、信号及去重状态。
- `data/server.log` / `data/server-error.log`：本地服务日志。
- moomoo 官方 SDK 自身会向其标准 AppData 日志目录写日志。
- `.runtime.json`：本项目后台进程标识，供停止脚本核对。
- 备份数据库前先停止后台，避免遗漏 SQLite WAL 尚未合并的内容。

主要代码：`app/provider.py`（OpenD）、`app/market.py`（日历和时间）、`app/analysis.py`（规则）、`app/engine.py`（监控）、`app/store.py`（SQLite）、`app/main.py`（HTTP）、`web/`（界面）。

## 当前边界

已实现分析、提醒、记录与基于 K 线的历史回测。逐根交互回放、样本外验证、自动同步券商持仓、盘前盘后策略、结构退出与移动保护、财报日历、手机远程访问尚未实现。信号规则未经过收益有效性验证；成交量倍数尚未校正日内季节性。

2026-11-26 联调时美股因感恩节休市，已经验证真实 OpenD 连接和历史行情同步。连续盘中推送和真实触发通知仍需下个交易时段验证；自动测试使用人工构造行情验证触发与拦截逻辑。
